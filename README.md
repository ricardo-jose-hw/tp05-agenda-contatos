Exercício proposto:
DUPLA 05 Agenda de Contatos Repositório sugerido: tp05-agenda-contatos Agenda telefônica em memória, com inclusão, listagem, busca por nome e exclusão lógica de contatos. 

Requisitos específicos 

• Vetores paralelos para nome, telefone e e-mail (capacidade 50). 
• Busca parcial por nome usando toLowerCase() e contains().
• Controlar a quantidade de contatos com uma variável contadora.
Dev Branch Responsabilidade A feature/inclusao-listagem Inclusão de contatos com verificação de agenda cheia e listagem numerada.
B feature/busca-exclusao Busca por parte do nome e exclusão com deslocamento dos elementos do vetor. 
Conflito obrigatório Os dois desenvolvedores devem reescrever, cada um em sua branch e sem combinar o conteúdo, as linhas do método exibirMenu(). 
O merge das duas branches na main deve gerar conflito, que será resolvido em conjunto e documentado no relatório

Divisão de Tarefas

Geral: Ambos os programadores fizeram seu próprio menu, justamente para ilustrar o conflito proposto do exercício. Mínimo de 5 commits para cada, totalizando 12.
Dev A (Lucas) - Programou as funções de inserção verificação e listagem de cada contato presente no vetor.
Dev B (Ricardo) - Codificou as funções de busca e remoção de contatos.
